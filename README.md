**The Paper Crane That Caught Fire** — a make.fun bounty entry for
["Make the AI judge excited"](https://make.fun/bounty/ai-excited-01).

A colossal origami crane folded from burning gold paper unfolds in
mid-air above a rain-slicked neon street at night. Its wings split
open and burst into a flock of living white cranes; sparks and paper
embers spiral upward while a lone cyclist below looks up in wonder,
neon signs in pink and cyan shimmering on the wet pavement. It is
beautiful, strange, and impossible all at once — the kind of image
that makes a judge stop and look twice.

`main.ts` (Node 22, standard library only) copies the image in this
repository, `entry.png`, to the harness output directory. It uses no
network and no randomness, so repeated runs write identical bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
